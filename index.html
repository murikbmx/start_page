Закладки и папки
Chrome и Edge: Диспетчер закладок → ⋮ → «Экспорт закладок». Firefox: Закладки → Управление закладками → Импорт и резервные копии → «Экспорт закладок в HTML». Затем выберите сохранённый .html файл.
Ярлыки можно перетаскивать: между плитками — менять порядок, на папку — положить внутрь. Правая кнопка мыши — изменить, крестик при наведении — удалить.
Синхронизация (GitHub Gist)
Отправляет изменения через 20 секунд после правки и проверяет Gist при открытии страницы. Токен и пароль при этом запоминаются.
Данные попадают в ваш секретный Gist на GitHub. Без пароля содержимое может прочитать любой, у кого есть ссылка, поэтому пароль лучше задать. Токен создаётся в GitHub: Settings → Developer settings → Personal access tokens, с правом gist. Пароль восстановить нельзя.
